# GABILEEN — розничный магазин мужской одежды

Мобильное веб-приложение (сайт + Telegram Mini App) розничного магазина мужской классики GABILEEN.
Сделано на основе электронного каталога VANVION, но переделано под розницу:

* **цена** — у каждого пиджака своя цена из поля `price` (сейчас у всех **25 000 ₽**);
* **размер выбирается** в карточке товара и в быстром окне «В корзину»: **50, 52, 54, 56, 58**;
* **без БАТАЛ** и без оптовых «пачек/ростовок»;
* в корзине — позиции «модель + цвет + размер», количество, сумма по строке и **итоговая сумма**;
* заказ отправляется менеджеру в WhatsApp, Telegram или MAX готовым текстом, например:

```
Здравствуйте! Хочу оформить заказ GABILEEN:

1. ПИДЖАК MILANO SONILI LACI (СИНИЙ, арт. PR-4303) — размер 54 × 1 шт. — 25 000 ₽

Итого: 1 товар на сумму 25 000 ₽
```

## Данные о товарах

Товары лежат в `data/products.json` (можно подключить Google-таблицу в CSV — см. `DATA_URL` в начале `<script>` в `index.html`).
Образец колонок — `gabileen-catalogue-template.csv`.

| Поле | Назначение | Пример |
|---|---|---|
| `id` | Артикул (уникальный) | `PR-2018` |
| `cat` | Категория: `pidzhaki`, `bryuki`, `palto` | `pidzhaki` |
| `name_ru` / `name_en` | Название | `ПИДЖАК SONILI SIYAH` |
| `model` | Модель — по ней цвета объединяются в одну карточку | `SONILI` |
| `colors` | Ключ цвета (см. `PALETTE` в `index.html`) | `siyah` |
| `image`, `image2` | Фото (путь в `images/` или прямая ссылка) | `images/PR-2018.jpg` |
| **`price`** | **Цена в рублях** | `25000` |
| **`sizes`** | **Размеры для выбора** — списком или диапазоном с шагом 2 | `50, 52, 54, 56, 58` или `50–58` |
| `comp_*`, `sil_*`, `lin_*`, `btn_*`, `country_*`, `ros_*` | Характеристики (рус./англ.) | `ШЕРСТЬ 100%` |

Чтобы поменять цену или размеры — измените `price` / `sizes` у нужных товаров.

**Нет в наличии.** Добавьте товару поле `soldout` с размерами, которых нет, например `"soldout": "56, 58"` —
эти кнопки станут зачёркнутыми и их нельзя будет выбрать.

## Доставка, примерка, размерная сетка

В начале `<script>` в `index.html`:

* `DELIVERY` — способы получения в корзине (курьер, выезд с примеркой, СДЭК, самовывоз).
  У каждого: название, пояснение и `price` — число в рублях, `0` = «бесплатно», `null` = «стоимость сообщит менеджер».
* `SIZE_CHART` — таблица размеров (обхват груди и талии в см), открывается по ссылке «Таблица размеров».

Покупатель в корзине выбирает способ получения и указывает имя, телефон и адрес — всё это попадает
в сообщение менеджеру вместе со списком товаров.

## Контакты

Телефоны, мессенджеры и адреса — объект `CONTACTS` в начале `<script>` в `index.html`.

## Публикация

Это статический сайт: достаточно включить GitHub Pages (Settings → Pages → Deploy from branch → `main`, папка `/`)
или выложить файлы на любой хостинг. Ссылки для превью в соцсетях (`og:url`, `og:image`) указаны на
`https://vanvion.github.io/GABILEEN/` — поменяйте их в `<head>`, если адрес будет другим.

## Шрифт и логотип

Шрифт — **Futura PT Book** (`futura-pt-book.ttf`). Логотип — `logo.svg`; иконки приложения
(`icon-512.png`, `apple-touch-icon.png`, `favicon.png`) и картинка превью `og-image.jpg` сделаны из него.
